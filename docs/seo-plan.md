# SEO plan for Bar Trivia Now

## Start with venues and launch regions

- Give every reviewed venue one stable URL per language. Put the name, neighbourhood or city, address, map link, upcoming trivia, regular schedule, entry or minimum spend, prizes, event language, and last source check on the page whenever verified. Link each schedule to its venue and source. Keep a venue URL stable across hosting and event changes.
- Build the first regional guides for Toronto and the GTA, Hamilton and Niagara, Waterloo Region, London, Ottawa, Montréal, Thunder Bay, Greater Sudbury, North Bay and Timmins. Publish an indexable guide when it has useful local material. Include current listings, areas served, venue links and local participation details that are actually known. Keep low-coverage pages honest and visible through the coverage directory.
- Add city pages when the catalog supports them with distinct venues and recurring schedules. Start with cities such as Toronto, Hamilton, Kitchener, Waterloo, Ottawa and Montréal. Add weekday pages only when they can answer a separate visitor question with enough live venues and the corresponding local schedules. Review city and weekday pages for overlap before indexing them.

## Add useful guides

- Publish original guides for finding a trivia night, what to expect at your first pub quiz, understanding buy-ins and minimum spends, playing solo or as a team, and finding French or bilingual trivia. Link to relevant real venues and current regional pages.
- Use published venue details and organizer guidance to explain reservations, age rules, team limits, quiz format or accessibility. Each guide should solve a visitor problem even if they arrive directly from search. Use the existing source-check process to update or retire stale advice.

## Set up discovery and measurement

- Render headings, venue details and links into the initial HTML. Give every indexable page a descriptive title, its own canonical URL, and reciprocal English and French alternate URLs where both versions exist. Keep personalized and faceted search URLs out of the sitemap.
- Submit the HTTPS sitemap in Google Search Console. Check representative venue, city and event URLs with URL Inspection. Start with a small batch, then measure impressions, clicks, indexed pages and pages excluded as duplicates or stale. [Google Search sitemap guidance](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap)
- Add structured data after visible details are stable. Use a venue and postal address for eligible venue pages. On an individual dated event page, add Event markup with a valid venue, start time and confirmed price when available. Use recurring schedules to link people to individual dates. Test representative examples before rollout. [Google Event structured data](https://developers.google.com/search/docs/appearance/structured-data/event)
- Review coverage and broken links weekly. Keep completed event dates out of the active sitemap. If a page still gets visits, display its date clearly and link to the next verified date or venue. When two pages serve the same intent, select a canonical and consolidate links.

## Order of work

1. Improve and verify the existing venue templates and their internal links.
2. Launch the first city guides from reviewed data and check their indexing.
3. Add the editorial guides and link each from its relevant city or venue pages.
4. Expand weekday pages and regional coverage as verified listings grow. Review the affected pages before each release.
